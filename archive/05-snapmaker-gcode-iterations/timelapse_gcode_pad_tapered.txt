; ===========================================================================
; FX30 camera trigger - Timelapse G-code box (tapered purge pad version)
;
; Shape: a wider brim on layer 1 only (two extra square rings around the
; pad footprint, like the brim OrcaSlicer adds around its own prime tower
; for bed adhesion), then a constant 6x6mm body on every layer after that -
; base bigger, top smaller, same idea as a real wipe tower.
;
; This replaces timelapse_gcode_pad.txt (the old 4x4mm flat pad). Two
; changes from that version: the pad is bigger (6x6mm body instead of
; 4x4mm) and it now travels TO the pad deliberately instead of assuming
; the switch-travel already got the nozzle there - so this version stands
; on its own regardless of what else changes in the switch/trigger part.
;
; Geometry, all centered around roughly (246, 265):
;   layer 1 only : two square rings, 10x10mm and 8x8mm (the "brim")
;   every layer  : one 6x6mm square, perimeter + infill lines (the "body")
; Adjust the coordinates below if this overlaps your model's footprint -
; I can't see your actual bed layout for the new shape, so double check in
; preview before printing a long job on this.
;
; Extrusion is calibrated for 0.2mm layer height / 0.42mm line width /
; 1.75mm filament (E per mm = 0.0349mm) - same formula as before. If you
; change layer height, these E values need to be recalculated, they're
; hand-computed for this specific profile, not derived from the slicer.
;
; No ;BEFORE_LAYER_CHANGE marker or G92 E0 here - the profile inserts
; those automatically regardless of what's in this box (confirmed
; earlier), same for TIMELAPSE_TAKE_FRAME / DEFECT_DETECTION_DETECT.
; ===========================================================================

; ---------------- FX30 camera trigger + purge pad ----------------
SAVE_GCODE_STATE NAME=fx30      ; remember position, feedrate and E mode
M83                              ; relative extrusion
G1 E-0.8 F2400                   ; retract, leaving the object clean
G91
G1 Z2 F1200                      ; lift 2mm clear of the print before
                                  ; heading over to the pad
G90

G1 X243 Y262 F18000               ; travel to the pad's near corner
G1 Z{layer_z} F1200                ; drop to this layer's height
G1 E0.8 F1800                      ; un-retract, ready to print the pad

{if layer_z <= 0.25}
; ---- brim: layer 1 only, wider footprint to anchor the pad to the bed ----
G1 X251.000 Y260.000 E0.3492 F600
G1 X251.000 Y270.000 E0.3492
G1 X241.000 Y270.000 E0.3492
G1 X241.000 Y260.000 E0.3492
G1 X250.000 Y261.000 E0.2794
G1 X250.000 Y269.000 E0.2794
G1 X242.000 Y269.000 E0.2794
G1 X242.000 Y261.000 E0.2794
G1 X243.000 Y262.000              ; back to the body's start corner, still primed
{endif}

; ---- body: printed every layer, this is what absorbs the per-trigger ooze ----
G1 X249.000 Y262.000 E0.2095 F600
G1 X249.000 Y268.000 E0.2095
G1 X243.000 Y268.000 E0.2095
G1 X243.000 Y262.000 E0.2095
G1 X248.700 Y262.300 E0.1886
G1 Y263.000 E0.0244
G1 X243.300 Y263.000 E0.1886
G1 Y263.700 E0.0244
G1 X248.700 Y263.700 E0.1886
G1 Y264.400 E0.0244
G1 X243.300 Y264.400 E0.1886
G1 Y265.100 E0.0244
G1 X248.700 Y265.100 E0.1886
G1 Y265.800 E0.0244
G1 X243.300 Y265.800 E0.1886
G1 Y266.500 E0.0244
G1 X248.700 Y266.500 E0.1886
G1 Y267.200 E0.0244
G1 X243.300 Y267.200 E0.1886

G1 E-0.8 F2400                     ; retract before heading to the switch
G1 X250 Y265 F18000                ; fast diagonal to the approach point
G1 X262.8 Y265 F6000                ; press the switch -> camera triggered
M400                                 ; wait for the move to actually finish
G4 P100                              ; hold the contact closed

G1 X248 Y265 F6000                    ; back off - lands right next to the
                                       ; pad, off the object
M400
G4 P2000                              ; hold still while the shutter fires

M83
G1 E0.8 F2400                         ; un-retract, ready to resume printing

RESTORE_GCODE_STATE NAME=fx30 MOVE=1 MOVE_SPEED=300
; the move above returns to the resume point on the object
; -------------- end FX30 camera trigger + purge pad --------------
