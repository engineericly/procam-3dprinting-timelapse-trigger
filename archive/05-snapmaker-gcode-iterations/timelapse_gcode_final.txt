; ===========================================================================
; FX30 camera trigger - Timelapse G-code box
; Self-contained purge version - no Orca prime tower, no forced filament
; change, no duplicate filament trick needed. You can remove that setup
; (the duplicate filament + height-range modifier) now that this doesn't
; depend on a real tower existing.
;
; This box fires at the same point "Before layer change G-code" did - we
; tested that directly, so no need for the ;BEFORE_LAYER_CHANGE marker or
; G92 E0 here, the profile already inserts those on its own regardless of
; what's in this box.
;
; Why no Orca tower: its own wipe tower travel (generated automatically
; right after this block) can't be controlled or reordered from here -
; it's Orca's internal tool-change code, and it travels flat regardless
; of Z-hop settings. This purge sidesteps that: no separate tower object,
; no extra travel, full control over amount, shape and position.
;
; The purge deposits a short 4mm line (not a single static dot) so it
; builds a stable ridge over the course of the print rather than a thin
; spike. It touches down at {layer_z} - the same value Orca tracks for
; the real layer height - so it grows in step with the print.
;
; Purge pad sits at X244-248, Y265: past the switch's own approach/release
; point (X248-262.8), so growth there never encroaches on the switch.
; ===========================================================================

; ---------------- FX30 camera trigger + self-purge ----------------
SAVE_GCODE_STATE NAME=fx30      ; remember position, feedrate and E mode
M83                              ; relative extrusion
G1 E-0.8 F2400                   ; retract, so the trip leaves no blobs
G91
G1 Z2 F1200                      ; lift 2mm clear of the print
G90

G1 X250 Y265 F18000              ; fast diagonal to the approach point
G1 X262.8 Y265 F6000              ; press the switch -> camera triggered
M400                              ; wait for the move to actually finish
G4 P100                           ; hold the contact closed

G1 X248 Y265 F6000                 ; back off clear of the switch
M400
G4 P2000                          ; hold still while the shutter fires -
                                   ; nozzle stays retracted through this
                                   ; whole dwell, still lifted

G1 Z{layer_z} F1200                ; touch down to this layer's actual
                                    ; height, right for the purge pad
G1 X244 Y265 E3.0 F150             ; slow deliberate purge along a short
                                    ; line - pushes out anything that
                                    ; oozed/degraded during the dwell,
                                    ; and builds a stable ridge over time
                                    ; instead of a single tall spike
M400
G4 P200                            ; brief settle before lifting off
G1 E-0.8 F2400                     ; retract again before leaving
G91
G1 Z2 F1200                        ; lift back up for the return trip
G90

RESTORE_GCODE_STATE NAME=fx30 MOVE=1 MOVE_SPEED=300
; the move above crosses back to the resume point while still retracted

M83
G1 E0.8 F2400                      ; un-retract only now, back at the
                                    ; resume point - ready to print
; -------------- end FX30 camera trigger + self-purge --------------
