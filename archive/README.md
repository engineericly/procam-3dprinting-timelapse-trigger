# Archive

Superseded code from every earlier phase of this project, organized into five dated subfolders by era: protocol probes, the Snapmaker U1 daemon, the Snapmaker U1 firmware, the Snapmaker U1 Klipper macros, and every Snapmaker U1 g-code box iteration. Kept for reference, not as a starting point for new work - see `../../decisions.md` for why each was dropped. Full catalog in `../index.md`.
